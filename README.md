# Modern GUI

**A clean, minimal, modern GUI overhaul for Minecraft Java Edition.**

Modern GUI reimagines Minecraft's interface with a sleek and refined visual design while preserving the familiar Minecraft aesthetic.

The goal is simple:

> **Make Minecraft's GUI feel modern without losing what makes it Minecraft.**

## ✦ Features

### ◼ Modern Interface

A redesigned GUI focused on clarity, consistency, and simplicity.

*   Clean interface panels
*   Refined borders
*   Minimal visual noise
*   Consistent UI elements
*   Improved contrast
*   Modern button styling

### ◻ Redesigned Buttons

Buttons are a key part of the Modern GUI experience.

### ◇ Minimal Design

The modern GUI removes unnecessary visual clutter while keeping important information easy to recognise.

Every element feels like part of the same interface.

**Simple. Clean. Consistent.**

## 🎨 Design Philosophy

Modern GUI isn't designed to replace Minecraft's identity.

Instead, it takes the familiar Minecraft interface and gives it a more contemporary visual language.

The result is a GUI that feels:

**Modern · Minimal · Clean · Refined · Minecraft**

## 📦 Compatibility

**Minecraft Java Edition 26.2**

The pack is designed around the modern Minecraft resource-pack system and is actively developed alongside the project.

## ⚙️ Installation

1.  Download the latest **Modern GUI** release.
    
2.  Open Minecraft Java Edition.
    
3.  Go to **Options → Resource Packs**.
    
4.  Open the Resource Pack folder.
    
5.  Place the `.zip` file inside.
    
6.  Enable **Modern GUI**.
    

**Do not extract the ZIP.**
